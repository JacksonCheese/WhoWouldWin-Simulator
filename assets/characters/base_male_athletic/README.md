# WWS Athletic Male Base

This repository-authored development asset is the reusable male humanoid foundation for medium-distance combat animation. It keeps the standard WWS humanoid rig contract and supports generic Actions, root trajectories, retargeting, IK contact correction, and character-specific package overlays.

The body receives a conservative athletic proportion pass, corrective joint smoothing, and practical hand silhouettes with `OPEN_PALM`, `CLOSED_FIST`, `RELAXED`, and `CUPPED` presets. Character packages remain responsible for costume, materials, head, hair, accessories, animation overrides, and abilities.

This is not a film-quality anatomy or hand rig. It is intended to improve combat silhouettes and deformation while preserving the validated production pipeline.
