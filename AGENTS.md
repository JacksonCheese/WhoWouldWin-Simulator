# Repository workflow

- After completing and validating any requested project change, commit all relevant source changes to Git and push the current branch to the configured `origin` remote.
- Use a concise commit message describing the completed outcome.
- Do not commit credentials, `.env` files, virtual environments, generated render frames, generated videos, Unity caches, or other ignored build artifacts.
- If a push cannot be completed because authentication or the remote is unavailable, keep the local commit and report the exact blocker.
